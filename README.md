## 🚀 How to Practice

1. Clone or download this repository.
2. Open the `datasets` folder.
3. Choose the dataset required for the topic.
4. Run the dataset SQL file in your database.
5. Open the relevant `questions.sql` file.
6. Try to solve each question without looking at the solution.
7. Run your query and check the result.
8. Compare your solution with `solutions.sql`.
9. Move to the next topic as your SQL skills improve.
