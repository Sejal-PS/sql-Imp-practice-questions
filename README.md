### 🔴 Advanced

## 🚀 How to Practice

1. Download or clone this repository.
2. Open the `datasets` folder.
3. Run `sample_data.sql` in your SQL database.
4. Choose a topic from the practice folders.
5. Open `questions.sql`.
6. Try to solve each question yourself.
7. Check your answers using `solutions.sql`.

## 🗄️ Database

You can practice these SQL questions using:

- MySQL
- PostgreSQL
- SQL Server
- SQLite

Some SQL commands may vary slightly between database systems.
